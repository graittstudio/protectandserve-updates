# Protect and Serve — updates

Hier staan alleen de installatiebestanden (APK) van de Android-app **Protect and Serve** van grAItt Studio.
De app kijkt zelf of hier een nieuwere versie staat en meldt dat met een popup.

- De broncode staat hier niet.
- Elke APK is ondertekend met het eigen certificaat van Protect and Serve. De app installeert geen update met een ander certificaat.
